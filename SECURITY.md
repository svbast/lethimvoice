# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately on GitHub: the
**Security** tab of this repository → **Report a vulnerability**.

Include what you found, how to reproduce it and the version you tested
(the About tab). We aim to reply within a week and keep you updated until it is
fixed.

## Supported versions

Only the latest release gets fixes. The app updates itself, so most people run it.
